# PORTFOLIOPRO REST API Specification

## 1. Overview & Conventions

All endpoints are hosted relative to the base URL:
```
http://localhost:8080/api
```

### Authentication Header
Protected endpoints require a valid JWT token transmitted via standard HTTP Authorization header:
```http
Authorization: Bearer <jwt_token>
```

### Standard Error Response Format
All error responses adhere to a consistent JSON envelope generated by `GlobalExceptionHandler`:
```json
{
  "timestamp": "2026-09-29T10:00:00.000+00:00",
  "status": 400,
  "error": "Bad Request",
  "message": "Insufficient shares to sell. You currently hold 5 shares.",
  "path": "/api/orders"
}
```

## 2. Authentication Endpoints

### 2.1 Register New User
Creates a new user account with BCrypt password hashing.

- **Endpoint**: `POST /api/auth/register`
- **Access**: Public
- **Headers**: `Content-Type: application/json`
- **Request Body**:
  ```json
  {
    "username": "trader_alice",
    "email": "alice@portfoliopro.com",
    "password": "Password123!"
  }
  ```
- **Validation Rules**:
  - `username`: Required, unique, non-blank
  - `email`: Required, unique, valid email format
  - `password`: Required, minimum 6 characters
- **Success Response** (`200 OK`):
  ```json
  {
    "message": "User registered successfully"
  }
  ```
- **Error Responses**:
  - `400 Bad Request`: Validation failure or duplicate username/email

### 2.2 User Login
Authenticates user credentials and issues a stateless JSON Web Token (JWT).

- **Endpoint**: `POST /api/auth/login`
- **Access**: Public
- **Headers**: `Content-Type: application/json`
- **Request Body**:
  ```json
  {
    "username": "demo",
    "password": "demo123"
  }
  ```
- **Success Response** (`200 OK`):
  ```json
  {
    "token": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJkZW1vIiwiaWF0IjoxNzI3NTg2MDAwLCJleHAiOjE3Mjc2NzI0MDB9...",
    "username": "demo"
  }
  ```
- **Error Responses**:
  - `401 Unauthorized`: Bad credentials or user not found

## 6. Simulated Trading & Orders Endpoints

### 6.1 Execute Trade Order
Submits and synchronously executes a simulated BUY or SELL order.

- **Endpoint**: `POST /api/orders`
- **Access**: Authenticated
- **Headers**:
  - `Content-Type: application/json`
  - `Authorization: Bearer <token>`
- **Request Body**:
  ```json
  {
    "stockId": 1,
    "type": "BUY",
    "quantity": 5,
    "price": 225.50
  }
  ```
- **Field Constraints**:
  - `stockId`: Valid existing stock ID
  - `type`: Must be `"BUY"` or `"SELL"`
  - `quantity`: Positive integer greater than 0
  - `price`: Positive number greater than 0.0
- **Execution Rules**:
  - **BUY**: If holding exists, updates holding quantity and recalculates weighted average purchase price. If holding does not exist, creates new holding record.
  - **SELL**: Validates that existing holding quantity $\ge$ requested quantity. If requested equals held quantity, holding record is deleted. If requested exceeds held quantity, rejects trade with HTTP 400.
- **Success Response** (`200 OK`):
  ```json
  {
    "orderId": 12,
    "symbol": "AAPL",
    "type": "BUY",
    "quantity": 5,
    "price": 225.50,
    "status": "EXECUTED",
    "createdAt": "2026-09-29T10:05:00"
  }
  ```
- **Error Responses**:
  - `400 Bad Request`: "Insufficient shares to sell. You currently hold X shares." or invalid input parameters.
  - `404 Not Found`: Stock ID does not exist.

### 6.2 Get Order History
Retrieves the authenticated user's historical order transactions ordered descending by date.

- **Endpoint**: `GET /api/orders`

## 9. Example cURL Workflows

### Authentication & Order Flow
```bash
# 1. Login
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"demo123"}' | jq -r .token)

# 2. Get Portfolio Summary
curl -s -X GET http://localhost:8080/api/portfolio/summary \
  -H "Authorization: Bearer $TOKEN" | jq .

# 3. Buy 5 shares of AAPL (Stock ID: 1)
curl -s -X POST http://localhost:8080/api/orders \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"stockId":1,"type":"BUY","quantity":5,"price":225.50}' | jq .

# 4. View Risk & Allocation Analytics
curl -s -X GET http://localhost:8080/api/portfolio/analytics \
  -H "Authorization: Bearer $TOKEN" | jq .
```
